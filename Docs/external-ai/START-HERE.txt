Jev 직접 선택 — 인터페이스 검증용

실제 Jev API와 키 없이 사용자가 판단하는 로컬 프로그램입니다.

바로 시험하기
1. PowerShell에서 tools/external-ai/Start-HumanJev.ps1 실행.
2. http://127.0.0.1:49173/ 열기.
3. ‘연습 질문으로 테스트’ → 질문마다 선택 → ‘선택 반환’.

Choice: 고른 항목만 true(1), 나머지는 false(0).
yes/no: true는 1, false는 0.
단계 선택: 고른 수준만 1, 나머지는 0. 퍼센트 입력은 없습니다.

게임 연결 앱과 함께 사용하기
Setup-ExternalAi.ps1로 연결 설정을 만들고 Start-ExternalAiBridge.ps1 실행.
다른 창에서 Start-JevApp.ps1 -CardData '추출 카드 폴더 절대 경로' -Provider human 실행.
직접 선택 프로그램은 계속 켜 둡니다. 기본 앱 모드도 human입니다.

확인한 결과
자동 검사 18개 통과. 브라우저에서 고른 6건이 실제 DLL에 적용됐습니다.
패 2번째 카드가 지정한 필드 구역 3에 놓인 것을 대조했습니다.
입력 기한 초과·취소·잘못된 답은 거절하고 자동 후보를 선택하지 않습니다.
실제 Jev 호출과 게임 화면의 전체 통합은 이번 검증 범위에 포함하지 않습니다.

포함: 수정 클라이언트·서버, 연결 앱, 직접 선택 더미와 화면, 실행 도우미.
게임 DLL·로더·추출 카드 자산·키·저장 파일은 포함하지 않습니다.
상세 설정과 입력 형식은 Docs/external-ai/README.md, protocol.md에 있습니다.
