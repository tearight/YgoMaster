YgoMaster + Jev 개발 패키지

들어 있는 것: 수정 클라이언트·서버 실행 파일, 별도 Jev 앱, 실행 도우미.
선택지 문장은 게임 상태·카드 사전·문장 틀로 만들며 LLM 호출을 쓰지 않습니다.

확인한 것: 실제 DLL의 소환·배치·마법 발동·대상 선택 등 요청 24개가 엔진에 적용됐습니다.
이 검증의 판단은 모의 앱을 사용했습니다. 실제 Jev 성공으로 기록하지 않습니다.
남은 것: 실제 Jev 호출, 게임 화면에서의 입력 경합, 다중 소재·코스트·문자열 치환.

앱 시작 순서:
1. tools/external-ai/Setup-ExternalAi.ps1 — 로컬 연결 설정 만들기
2. tools/external-ai/Start-ExternalAiBridge.ps1 — 중계 서버 실행
3. tools/external-ai/Start-JevApp.ps1 -CardData '추출 카드 폴더 절대 경로' — Jev 앱 실행

JEV_API_KEY는 환경변수로 준비합니다. 키를 채팅이나 설정 파일에 넣지 않습니다.
게임 DLL·카드 자산·로더는 포함하지 않습니다. 기존 YgoMaster 실행 환경이 필요합니다.
기존 캠페인에 배치하는 완성 버전은 아직 아닙니다.
상세 설정과 확인 결과는 Docs/external-ai/README.md와 coverage.md에 있습니다.
